# 추천 모델 검증 자료

앱의 추천 점수가 어떻게 검증됐는지 그대로 재현할 수 있는 스크립트와 결과입니다.

- `backtest.json` — 확정 모델의 82개월 월별 수익률(모델·동일가중·시총가중·KOSPI), 통계, 부트스트랩 신뢰구간
- `event_study.json` — 공시 14종의 사건연구(KOSPI 조정 누적초과수익률)
- `fx_paper.json` — 환율 결정모형 재현(통화론 vs 주식시장 모형, 표본외 비교)
- `factors.py` → `fund.py` → `t_52w.py` → `t_flow.py` 순서로 패널을 만들고, `t_final.py`가 확정 모델을 평가합니다.
- `harness.py` — 공통 평가 도구(상위 15종목 동일가중, 왕복 거래비용 0.6%, Newey-West t)

원칙: 종목을 고르는 날보다 먼저 접수된 재무제표·공시만 사용합니다. 시도한 결합 모델은 약 15개이며, 자사주 요인은 단독 검증 결과를 본 뒤 추가했습니다.
